# D T Akshay Raj - Portfolio

A responsive single-page portfolio generated from the resume provided for D T Akshay Raj.

## Files
- `index.html` - portfolio structure and content
- `style.css` - responsive styling and animations
- `README.md` - this file

## Run locally
Open `index.html` directly in a browser, or use a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before deploying
Replace the placeholder `#` links for LinkedIn and GitHub in `index.html` with the actual profile URLs.
